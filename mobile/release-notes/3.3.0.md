Oruinwan 3.3.0 makes groups, threads and tasks work together and tightens who can see what. It's a quick update on phones and the desktop app; no reinstall.

- **Adding people to a group:** you choose what they see: "From now on" or "Include earlier messages". Their access follows that choice everywhere, and the group's encryption key changes so earlier messages stay private when you pick "From now on".
- **Start a new group instead:** next to "Add people", start a separate group with everyone plus the new people. The original group stays as it is.
- **Removing someone** from a group or a private channel now gives it a new key, so they can't read what comes next.
- **Tasks and threads share comments:** for a task made from a message, comments in the task show up in the chat thread and replies in the thread show up in the task, each only for people allowed to see it. Each comment says whether it reached the thread.
- **New message search** finds the same people the same way on the web and the phone; group pickers no longer list people who left.
- **Steadier sending:** if a conversation's key changes while you send, the app resends with the new key on its own.
- **Privacy fixes:** live updates about older messages and threads no longer reach group members who joined later, and resolving a thread follows the same access rules as reading it.
