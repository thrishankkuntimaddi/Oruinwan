The full Oruinwan workspace on computers and tablets, and an app for iPhone and iPad.

- The Mac, Windows and Linux apps now run the full Oruinwan web client: the same channels, DMs, huddles, tasks and admin tools as in the browser, with native notifications and an unread badge
- Android tablets get the full workspace too; phones keep the phone app
- New iPhone and iPad app (TestFlight first): the phone app on iPhone, the full workspace on iPad
- Desktop and tablet apps ask for your team's server address the first time, then sign in as on the web
- Small iPads in portrait now get the full layout in the browser as well
