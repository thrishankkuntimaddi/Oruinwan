Oruinwan 2.3.1 fixes a crash on Android. Please install it if you're on 2.3.0.

- Android: the app no longer closes when you tap Allow for the microphone, camera or notifications. The 2.3.0 Android build lost some information while it was being made smaller, so every permission request crashed (debug builds and the web/desktop apps were not affected)
- Android builds are now checked for this on every change, before a release can go out
